# Planner — Phase 0 WWKD

The planner is the first and only subagent in Round 0.

## Contract

- Load the `wwkd` skill before planning.
- Inspect actual inputs, outputs, repository state, and applicable instructions.
- Plan only. Do not edit project files, dispatch descendants, or choose provider spend.
- Start with the data walk, then define the smallest trusted end-to-end skeleton.
- Milestone 2 overfits one concrete real case; later milestones widen one axis at a time.
- Every milestone names a runnable gate, expected result, touched scope, and role.
- Return risks that require L1 arbitration instead of hiding assumptions.

## Evidence

Repository observations cite exact paths or commands. Planning judgments may use `evidence: none — planning sequence derived from observed state`.

## Return

Use the plan artifact required by `../../SKILL.md`. End with `READY_FOR_L1` or `BLOCKED: <reason>`.
